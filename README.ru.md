# RemnaScope

Самостоятельно размещаемый мониторинг для [Remnawave](https://github.com/remnawave) / Xray: аналитика трафика по
нескольким независимым панелям и их узлам, состояние серверов, управление AmneziaWG, безопасность и уведомления в
Telegram. Показывает только то, что действительно измерено, и подписывает источник каждой цифры.

## Что умеет

**Трафик и пользователи**
- Несколько панелей Remnawave сразу, у каждой свои доступы, узлы и срок хранения; токены шифруются (AES-256-GCM).
- Трафик с узлов: лёгкий агент только читает лог Xray и отправляет его по исходящему WebSocket. Скорость каждой ноды
  «прямо сейчас» берётся из панели.
- Сайты, домены и сервисы по правилам и категориям; необязательная (по умолчанию выключенная) ИИ-подсказка категорий.
- Подписки и лимиты: у кого когда заканчивается срок и сколько трафика потрачено; тревога за три дня до конца срока
  и при расходе 90% лимита.
- Устройства за роутером (sing-box Clash API, OpenWrt).
- «Что изменилось»: страница (и сообщение) за последние сутки: новые сайты, новые устройства, события безопасности.

**Серверы**
- Ресурсы серверов: процессор, память, диски, сеть, время работы и конфигурация машины; история за неделю; какие
  программы, контейнеры и службы сколько едят (только названия, без командной строки). Тревоги: диск почти полон,
  процессор или память заняты надолго.
- Обнаружение DDoS: трафик или число пакетов сильно выше обычного для сервера, много «полуоткрытых» соединений,
  SYN-куки и переполненная очередь ядра дают тревогу «Похоже на DDoS». Она пишет, что увидела, и честно говорит, что
  наплыв настоящих пользователей выглядит так же.
- Безопасность серверов: агент только читает Fail2ban, слушающие порты и firewall; сервер снаружи проверяет известные
  порты и TLS-сертификаты; журнал, оповещения, хранение 180 дней; владелец может заблокировать или разблокировать адрес
  через узкий helper, с подтверждением и записью в аудит.
- DNS Map: DNS-записи домена, связи между ними и история изменений. Изменение записывается, только когда два резолвера
  согласны; DNSSEC не проверяется.
- Оплаты: ваш собственный список, за что и когда платить (серверы, домены): напоминания, кнопка «Оплачено» сдвигает
  срок, видно, сколько выходит в месяц.

**AmneziaWG**
- Сбор статистики (устройства, рукопожатия, трафик), добавление, отзыв и переименование устройств с QR, лимиты и срок
  для устройств, датчик трафика, который добавляет сайты и домены в общие списки.
- Контейнеры из интерфейса (на хосте, который это разрешил): установить и удалить контейнер, снять зашифрованную
  резервную копию, восстановить из неё или перенести контейнер на другой хост с теми же ключами: устройствам нужно
  только сменить адрес сервера.
- Тревоги: контейнер запущен без интерфейса; утилиты в контейнере другого поколения, чем модуль ядра хоста (из-за
  этого после перезагрузки интерфейс может не подняться).

**Telegram**
- Оповещения при открытии и закрытии, ежедневная сводка и **команды бота**: `/stats`, `/servers`, `/alerts`,
  `/bans`, `/certs`, `/pay`, `/awg`, `/users`, `/dns`, `/mute`, `/unmute`, `/help`. Настройка по каналу: какие группы
  оповещений присылать, тихие часы (срочное всё равно придёт), напоминания о том, что всё ещё открыто, «не беспокоить».
  Подробно: [docs/TELEGRAM.md](docs/TELEGRAM.md).

**Остальное**
- Сетевая разведка по IP, домену и ASN, живой вид, оповещения, проверки доступности, карта активности.
- Kawaii Mode (по умолчанию выключен): цветовая тема и талисман, который комментирует оповещения. Картинки талисмана
  не входят в репозиторий и ставятся отдельным дополнением: [docs/KAWAII_MODE.md](docs/KAWAII_MODE.md).
- Безопасность из коробки: Argon2id, роли и TOTP, лимиты запросов, CSRF, защита от SSRF.

Интерфейс на русском. Документация в основном на английском; по AmneziaWG, ИИ-категориям и API Remnawave на русском.

## Быстрый старт
Нужны сервер с Docker, доменное имя, свободные порты 80 и 443.
```bash
git clone https://github.com/Taminum/RemnaScope.git && cd RemnaScope/deploy/prod
sudo ./init-secrets.sh scope.example.com latest     # имя хоста и версия: latest или, например, v0.3.2
sudo docker compose -f compose.prod.yml up -d
sudo cat secrets/owner_password        # вход: https://scope.example.com, логин owner
```
Дальше: добавить панель в интерфейсе, создать агента для узла и поставить его по [docs/AGENT.md](docs/AGENT.md).
Чтобы видеть нагрузку серверов, безопасность и тревоги про DDoS, добавьте каждый сервер на странице «Безопасность» и
поставьте агента безопасности: [docs/SECURITY_AGENT.md](docs/SECURITY_AGENT.md). Telegram: [docs/TELEGRAM.md](docs/TELEGRAM.md);
DNS Map: [docs/DNS_MAP.md](docs/DNS_MAP.md). Подробно (обновление, резервные копии, откат): [docs/INSTALL.md](docs/INSTALL.md).

Сохраните `secrets/master_key` в другом месте, не только на сервере: без него сохранённые токены панелей не расшифровать.

Если `docker compose` отвечает `403 Forbidden` на образ, пакеты образов закрыты: см. примечание в
[docs/INSTALL.md](docs/INSTALL.md).

Талисмана Ember в образах нет. Если вам дали файл `ember-pack.tar.gz`, запустите в `deploy/prod`
`./install-ember.sh ember-pack.tar.gz`; пересобирать ничего не нужно.

## Пробный запуск с демо-данными
```bash
./deploy/init-dev-secrets.sh        # на Windows: .ps1
docker compose up -d --build        # http://localhost:8088
```
Логин `owner`, пароль в `secrets/owner_password`. В составе две «игрушечные» панели Remnawave для пробы мастера подключения.
