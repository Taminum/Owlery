# RemnaScope

Самостоятельно размещаемая аналитика трафика для [Remnawave](https://github.com/remnawave) / Xray: одна панель над
несколькими независимыми панелями и их узлами. Показывает только то, что действительно измерено, и подписывает
источник каждой цифры.

## Что умеет
- Несколько панелей Remnawave сразу, у каждой свои доступы, узлы и срок хранения; токены шифруются (AES-256-GCM).
- Трафик с узлов: лёгкий агент только читает лог Xray и отправляет его по исходящему WebSocket.
- Сайты, домены и сервисы по правилам и категориям; необязательная (по умолчанию выключенная) ИИ-подсказка категорий.
- Устройства за роутером (sing-box Clash API, OpenWrt).
- Серверы AmneziaWG: сбор статистики, добавление и отзыв устройств, датчик трафика, который добавляет сайты и домены в общие списки.
- Сетевая разведка по IP, домену и ASN, живой вид, оповещения, проверки доступности, карта активности.
- Безопасность из коробки: Argon2id, роли и TOTP, лимиты запросов, CSRF, защита от SSRF.

Интерфейс на русском. Документация в основном на английском; по AmneziaWG и ИИ-категориям на русском.

## Быстрый старт
Нужны сервер с Docker, доменное имя, свободные порты 80 и 443.
```bash
git clone https://github.com/Taminum/RemnaScope.git && cd RemnaScope/deploy/prod
sudo ./init-secrets.sh scope.example.com v0.1.0
sudo docker compose -f compose.prod.yml up -d
sudo cat secrets/owner_password        # вход: https://scope.example.com, логин owner
```
Дальше: добавить панель в интерфейсе, создать агента для узла и поставить его по [docs/AGENT.md](docs/AGENT.md).
Подробно (обновление, резервные копии, откат): [docs/INSTALL.md](docs/INSTALL.md).

Сохраните `secrets/master_key` в другом месте, не только на сервере: без него сохранённые токены панелей не расшифровать.

## Пробный запуск с демо-данными
```bash
./deploy/init-dev-secrets.sh        # на Windows: .ps1
docker compose up -d --build        # http://localhost:8088
```
Логин `owner`, пароль в `secrets/owner_password`. В составе две «игрушечные» панели Remnawave для пробы мастера подключения.
